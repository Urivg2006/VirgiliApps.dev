# Decimal Dates ⏱️

Converteix qualsevol data en **anys decimals** a l'instant.

Afegeixes una data (aniversari, fita, esdeveniment) i l'app t'indica quants anys han passat o quants en queden, amb els decimals que triïs.

```
Aniversari       12/03/2014  →  12,71 anys transcorreguts
Viatge           01/07/2027  →  −0,60 anys restants
```

## Funcionalitats

- **Esdeveniments** amb nom, data i hora opcional.
- **Anys decimals** amb la precisió que triïs, d'1 a 8 decimals.
- **Actualització automàtica** a l'interval òptim per a la precisió triada.
- **Avisos locals** quan arriba la data i cada any (amb permís del sistema).
- **Tres estils de widget** d'inici, redimensionables, amb colors per al passat i per al futur.
- **Mode clar i fosc**, també al widget.
- **20 idiomes**, canviables sense reiniciar l'app.
- **Calaix lateral** amb totes les opcions.

## Privacitat

Les dates es guarden **només al teu dispositiu**. L'app no té comptes ni servidors propis i no recull dades personals.
